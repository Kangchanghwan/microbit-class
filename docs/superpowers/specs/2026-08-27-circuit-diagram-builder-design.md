# 마이크로비트 회로도 제작 도구 — 설계 문서

날짜: 2026-08-27

## 배경

교사가 마이크로비트 + 센서:bit(유사) 확장보드에 각종 부품(OLED, 서보모터, 노이즈센서, 네오픽셀, 물센서, 릴레이, 딸깍스위치, 선풍기, 워터펌프, 빛센서 등)을 연결하는 프로젝트를 진행 중이며, 참고용 배선 스크린샷(`image1.png`)과 확장보드 핀맵 이미지(`breakeboard.jpeg`)를 보유하고 있다. 이 스크린샷 속 부품 사진들을 개별 이미지로 잘라내어, 교사가 자유롭게 배치하고 선으로 연결해 깔끔한 회로도를 만든 뒤 학생들에게 배포할 수 있는 웹 도구가 필요하다.

## 핵심 용도

교사용 회로도 제작 도구. 교사가 부품을 배치·연결해 회로도를 완성하면, 그 결과를 이미지로 저장하거나 학생에게 보기 전용 링크로 공유한다. 학생은 도구를 직접 조작하지 않고 결과만 본다.

## 배포 형태

공유 가능한 웹 링크 (Artifact) 하나로 배포한다. 서버나 로그인 없이 브라우저에서 바로 동작한다.

- URL에 파라미터가 없으면 **편집 모드**: 전체 편집 도구(팔레트, 드래그, 전선 연결, 부품 추가 등)가 활성화된다.
- URL에 `#view=<인코딩된 회로 데이터>`가 있으면 **보기 전용 모드**: 편집 UI를 숨기고, 완성된 회로도와 핀 연결 요약표만 보여주며 이미지 저장 버튼만 남긴다.

같은 Artifact 링크 하나가 두 역할을 모두 수행한다.

## 데이터 모델

- **보드(Board)**: `breakeboard.jpeg`를 배경으로 사용하는 고정 요소 1개. 핀 0~16, 3V, GND 등 각 핀 그룹을 "커넥터 포인트"(x, y 좌표 + 색상: 빨강/검정/노랑)로 정의해둔다.
- **부품(Part, 라이브러리 아이템)**: 이름, 잘라낸 이미지(PNG), 커넥터 포인트 좌표 1개(사진 속 검은 커넥터 하우징 위치)로 구성된다. `image1.png`에서 잘라낸 기본 10종(빛센서, 서보모터, 노이즈센서, 네오픽셀, 물센서, 릴레이 스위치, 딸깍 스위치, 선풍기, 워터펌프, OLED 모니터)을 기본 라이브러리로 등록한다.
- **배치된 부품(Placed Component)**: `{ partId, x, y }` — 캔버스 위 자유 위치.
- **전선(Wire)**: `{ from: 커넥터 참조, to: 커넥터 참조, color }` — 부품당 전선 1가닥(단색)으로 표현한다. 중간에 다른 모듈(예: 릴레이)이 끼는 경우는 전선 2개(부품→릴레이, 릴레이→보드핀)로 표현한다. 전선의 시작/끝은 보드 핀 커넥터 또는 부품 커넥터 중 하나다.
- **회로 상태(Diagram State)**: `{ placedComponents[], wires[] }` — 보드는 항상 고정이므로 상태에 포함하지 않는다.

## 상호작용 흐름 (편집 모드)

1. 왼쪽 팔레트에서 부품을 클릭하면 캔버스에 추가되고, 자유롭게 드래그로 위치를 옮길 수 있다.
2. 부품의 커넥터 점을 클릭한 뒤 보드 핀(또는 다른 부품의 커넥터)을 클릭하면 전선이 완성된다. 기본 색상은 연결 대상 보드 핀 열의 색(빨강/검정/노랑)을 따르되, 클릭으로 색을 바꿀 수 있다.
3. 배치된 부품이나 전선을 클릭해 선택 후 삭제할 수 있다.
4. 우측/하단에 "핀 연결 요약표"(예: "1번 핀 — 빛센서")가 연결 상태에 따라 실시간으로 자동 갱신된다.
5. 상단 툴바:
   - **이미지로 내보내기**: 별도 `<canvas>`에 배경+부품+전선+요약표를 다시 그려 PNG로 렌더링하고 `<img>`로 화면에 표시한다. 사용자가 우클릭 → 이미지로 저장한다 (Artifact 샌드박스는 스크립트 트리거 다운로드를 막으므로 우클릭 저장 방식을 사용한다).
   - **학생 공유 링크 생성**: 현재 회로 상태를 URL 해시로 인코딩해 복사 가능한 보기 전용 링크를 만들어준다.
   - **부품 추가**: 이미지를 업로드하고, 업로드한 이미지 위를 클릭해 커넥터 점을 지정한 뒤 이름을 입력하면 라이브러리에 저장된다.

## 보기 전용 모드 (학생용)

`#view=` 해시가 있으면 편집 UI(팔레트, 부품 추가, 드래그 핸들 등)를 숨기고, 완성된 회로도와 핀 연결 요약표만 정적으로 표시한다. 이미지 저장 버튼은 유지한다.

## 저장/영속성

브라우저 `localStorage`에 다음 두 가지를 저장한다:
- 교사가 업로드한 커스텀 부품 라이브러리 (세션 간 유지, 재사용 가능)
- 마지막으로 편집 중이던 회로 초안 (새로고침해도 유지)

이 저장소는 해당 브라우저에만 남으며 다른 사람과 자동으로 공유되지 않는다. 학생과의 공유는 위의 URL 해시 링크 방식으로만 이루어진다.

## 제약 및 에지 케이스

- 데스크톱/노트북 사용을 기준으로 설계한다. 드래그와 정밀 클릭이 중심이므로 모바일 터치 최적화는 하지 않는다.
- 회로 유효성 검증(예: "이 핀에는 이 부품을 연결하면 안 된다")은 하지 않는다. 자유롭게 배치·연결하는 교사용 제작 도구이기 때문이다.
- 외부 CDN 스크립트/라이브러리를 사용할 수 없으므로(Artifact CSP 제약), 모든 로직은 순수 HTML/CSS/JS로 인라인 구현하고 이미지는 데이터 URI로 내장한다.

## 테스트 방법

수동으로 Artifact를 열어 다음을 확인한다:
- 부품을 팔레트에서 추가하고 드래그로 위치를 옮길 수 있는가
- 커넥터 점끼리 클릭으로 전선을 연결/삭제할 수 있는가
- 핀 연결 요약표가 실시간으로 정확히 갱신되는가
- 이미지 내보내기 버튼으로 완성된 회로도를 우클릭 저장할 수 있는가
- 학생 공유 링크를 새 탭에서 열었을 때 보기 전용 모드로 정확히 렌더링되는가
- 부품 추가 기능으로 새 이미지를 업로드하고 커넥터 점을 지정해 라이브러리에 저장할 수 있는가, 새로고침 후에도 유지되는가
